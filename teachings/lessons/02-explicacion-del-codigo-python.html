1. La Estructura Nodo en Python

from dataclasses import dataclass
import heapq
import math

@dataclass
class Nodo:
    selec: bool = False
    costo: float = math.inf
    prev: int = 0
  • heapq: Módulo nativo de la biblioteca estándar de Python que implementa las operaciones de un Min-Heap binario sobre una lista estándar.
  • math.inf: Constante de punto flotante que representa el infinito ($\infty$) para nodos aún no alcanzados.

Pregunta Clave del Profesor: "¿Por qué en la tupla (0, 0) el costo va primero y el vértice segundo?"
Respuesta: Porque Python compara tuplas de manera lexicográfica (compara primero el índice 0, y solo en caso de empate compara el índice 1). Para que el Min-Heap ordene automáticamente por menor distancia acumulada, el costo debe ser el primer elemento de la tupla (costo, vertice).

3. La Inicialización: crear_arreglo()

Versión Cátedra Variante Óptima 
def crear_arreglo(grafo: GrafoTDA) -> list[Nodo]:
    cant = grafo.vertices()
    arreglo: list[Nodo] = []
    for i in range(cant):
        nodo = Nodo(False, math.inf, 0)
        if i == 0:
            nodo.selec = True
            nodo.costo = 0
        elif grafo.existe_arista(0, i):
            nodo.costo = grafo.peso_arista(0, i)
        arreglo.append(nodo)
    return arreglo
 
def crear_arreglo(grafo: Grafo) -> list[Nodo]:
    cant = grafo.vertices()
    arreglo = [
        Nodo(False, math.inf, 0)
        for _ in range(cant)
    ]
    if cant > 0:
        arreglo[0].costo = 0
    return arreglo

4. La Propagación: actualizar() y Lazy Deletion

Versión Cátedra Variante Óptima 
def actualizar(grafo, a, i) -> None:
    for j in range(len(a)):
        if not a[j].selec and grafo.existe_arista(i, j):
            nuevo = a[i].costo + grafo.peso_arista(i, j)
            if nuevo < a[j].costo:
                a[j].costo = nuevo
                a[j].prev = i
 
def actualizar(grafo, a, q, i) -> None:
    for j, peso in grafo.adyacentes(i):
        if not a[j].selec:
            nuevo = a[i].costo + peso
            if nuevo < a[j].costo:
                a[j].costo = nuevo
                a[j].prev = i
                heapq.heappush(q, (nuevo, j))
¿Cómo opera el Lazy Deletion en Python?
En un Min-Heap sin punteros invertidos, modificar una clave arbitraria (decrease_key) requeriría recorrer la lista en O(V). En su lugar, simplemente insertamos la nueva tupla con menor costo en O(log V). La tupla de menor costo saldrá primero de la cola y consolidará el nodo marcando arreglo_u[j].selec = True. Cuando más adelante la tupla vieja obsoleta llegue a la cima, la línea if arreglo_u[i].selec: continue la detecta y la descarta en O(1) sin volver a relajar sus aristas.
